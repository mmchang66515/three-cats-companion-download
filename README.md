## Android 手機安裝方式

1. 下載 APK。
2. 開啟手機的「檔案」或「下載」。
3. 點選 APK 檔案。
4. 若手機出現提示，允許瀏覽器或檔案管理員「安裝未知應用程式」。
5. 按下「安裝」即可。
