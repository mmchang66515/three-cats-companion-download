## Android 手機安裝方式

1. 點上方下載連結。
2. 開啟手機的「檔案」或「下載」。
3. 點選 APK 檔案。
4. 若手機出現提示，允許瀏覽器或檔案管理員「安裝未知應用程式」。
5. 按下「安裝」即可。

> 若顯示「應用程式套件與現有套件衝突」，請先解除安裝手機中的舊版「三貓陪你」，再安裝 v0.7.2。
